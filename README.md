# Музей пивной атрибутики

Статический сайт для GitHub Pages: главная страница `index.html` и отдельная страница для каждой кружки.

## Как опубликовать
1. Загрузите **всё содержимое** этой папки в корень репозитория (вместе с папками `assets/` и `img/` и файлом `.nojekyll`).
2. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Через минуту сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Имена страниц
Имена файлов взяты из столбца «№ п/п». Пробелы убраны, а кириллические буквы заменены латинскими, чтобы ссылки и QR-коды работали надёжно:

| № п/п | файл |
|---|---|
| 393 а | `393a.html` |
| 395 б | `395b.html` |
| 605 а | `605a.html` |

Остальные — как в таблице: `007.html`, `024.html`, `103.html` и т. д.

## Фотографии экспонатов
Пока фото нет, на витрине показывается векторная иллюстрация кружки. Чтобы добавить фото, положите файл в папку `img/` с тем же именем, что у страницы:
`img/007.jpg`, `img/393a.jpg`, `img/605a.jpg` … — фото заменит рисунок и на странице экспоната, и в карточке на главной. Лучше всего подходят вертикальные снимки 4:5 (например, 1200×1500).

## Анимации
Появление блоков при прокрутке, «парящая» кружка с поднимающимися пузырьками, блик на витрине, полоса прогресса чтения, фирменные эффекты у каждого завода. Если в настройках телефона или компьютера включено «Уменьшить движение», анимации автоматически отключаются.

## Структура
- `index.html` — главная «Музей пивной атрибутики» (залы, поиск и фильтры, лента времени)
- `NNN.html` — страницы экспонатов
- `assets/exhibit.css` — общий каркас страниц, `assets/themes.css` — оформление заводов, `assets/index.css` — стили главной, `assets/museum.js` — анимации
- `404.html` — страница «Витрина пуста»
